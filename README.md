# The Luxury Classroom: initial draft

Open index.html in a browser. No installation or server is needed.

Use “View all screens” to explore visitor, member and admin screens.

Try these flows:
- Add a guide and course to the cart, simulate checkout, then open My purchases.
- Choose Essential or Premium, simulate checkout, then explore the member library and billing.
- Choose a consultation, date and time, simulate payment, then open My bookings.
- Open a course's free lesson, mark it complete and explore the locked lessons.
- Open Admin demo to inspect the sample product and course editors.

This is a basic flow draft, not a finished design. All data stays in memory and resets on refresh. Payments, authentication, video, meetings and uploads are placeholders. Guide downloads are sample text files. Admin saves only show confirmation; they do not update the catalogue. No backend or third-party dependencies.
